# AQI API Check

Air Quality Index checker application that provides real-time air quality information and neighborhood insights.

## Features

- **Air Quality Checker**: Check the Air Quality Index (AQI) for any location by entering city, state, and country
- **Neighborhood Insights**: Explore neighborhoods with interactive map and nearby amenities
  - Search for locations
  - Find nearby hospitals, schools, groceries, airports, and more
  - View results on an interactive Google Map

## Getting Started

1. Clone the repository
2. Open `index.html` in a web browser to use the AQI checker
3. Navigate to `neighborhood-insights.html` for neighborhood exploration

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Maps API
- Font Awesome Icons
- Google Fonts (Montserrat)

## Usage

### AQI Checker
1. Enter a city name
2. Enter a state or province
3. Enter a country
4. Click "Check Air Quality" to view results

### Neighborhood Insights
1. Search for a location or click on the map
2. Select an amenity type (hospitals, schools, etc.)
3. View nearby locations on the map
4. Check AQI for the selected area
